# Настройка EasyGold в @BotFather

Готовые тексты — можно копировать целиком. Всё делается в переписке с [@BotFather](https://t.me/BotFather).

---

## 1. Создать бота

```
/newbot
```

**Имя** (отображается в шапке чата, можно менять когда угодно, разрешены пробелы и эмодзи):

```
EasyGold
```

**Юзернейм** (менять нельзя, должен заканчиваться на `bot`). Проверьте по очереди, какой свободен:

```
EasyGoldKZ_bot
easygold_kz_bot
EasyGoldShop_bot
EasyGoldStandoff_bot
```

Совет: берите тот, где `easygold` читается целиком и без лишних цифр — юзернейм будете писать в каждом видео и в каждом посте.

BotFather вернёт токен вида `8123456789:AAF...`. Это пароль от бота — в переписки не кидать, в git не коммитить, хранить только в `.env`.

## 2. Описание (пустой экран до нажатия «Начать»)

```
/setdescription
```

```
EasyGold — голда Standoff 2 в тенге.

• Выдача 5–15 минут
• Оплата через Kaspi
• Пароль от аккаунта не нужен — только игровой ID
• Не пришло — вернём деньги

Нажмите «Начать».
```

Это первое, что видит человек, перешедший по ссылке из TikTok. До 512 символов.

## 3. Короткое «О себе» (в профиле бота и в пересланных сообщениях)

```
/setabouttext
```

```
Голда Standoff 2 за 3 минуты. Оплата Kaspi. Пароль не нужен — только игровой ID.
```

До 120 символов.

## 4. Команды в меню

```
/setcommands
```

```
start - Купить голду
myorder - Мой заказ
cancel - Отменить
```

Команды оператора (`/orders`, `/stats`, `/whoami`) в этот список **не добавляйте** — они работают, но покупателям их видеть незачем.

## 5. Аватар

```
/setuserpic
```

Квадратная картинка, минимум 512×512. Что должно быть видно на кружке 40 пикселей в списке чатов: буква или монета плюс контрастный фон. Мелкий текст и логотип игры не читаются — и логотип Standoff 2 использовать нельзя, это чужой товарный знак.

## 6. Закрыть лишнее

```
/setjoingroups
```
→ **Disable**. Бот работает только в личке, в группах ему делать нечего.

```
/setinline
```
→ **Disable**, если BotFather спросит. Инлайн-режим не используется.

---

## Проверка перед запуском

- [ ] Токен вставлен в `bot/.env`, файл не в git
- [ ] `ADMIN_USERNAME` в `.env` — ваш юзернейм **без собаки**
- [ ] Написали боту `/start` со своего аккаунта и получили «Вы привязаны как оператор»
- [ ] В `config.json` заменили номер Kaspi и имя получателя на настоящие
- [ ] В `config.json` заменили `brand.support` на свой юзернейм
- [ ] Цены пересчитаны от реальной закупки, а не оставлены как в примере
- [ ] Прошли весь путь покупателя со второго аккаунта: выбор → ID → повтор ID → оплата → «Я оплатил» → «Выполнено»
- [ ] Проверили, что заказ приходит вам и кнопки работают

## Ссылка для продвижения

```
https://t.me/ВАШ_ЮЗЕРНЕЙМ
```

Можно давать ссылку сразу на конкретное действие:

```
https://t.me/ВАШ_ЮЗЕРНЕЙМ?start=tiktok
```

Всё после `?start=` приходит в бота как параметр — по нему потом можно считать, откуда пришёл человек. Сейчас бот параметр не разбирает, но ссылки с метками уже можно раздавать: когда добавим учёт источников, вся статистика по старым ссылкам сохранится.
